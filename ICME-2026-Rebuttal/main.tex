\noindent\textcolor{rev8color}{\textbf{$\triangleright$ Reviewer\#8.}}

\textbf{Q1:} ADRF-Fusion's global weights make "Adaptive" questionable.\\
A: The “Adaptive” refers to data-driven, task-adaptive weights learned end-to-end via Softmax, rather than manually fixed fusion weights. Although global, these weights automatically adapt to multi-scale feature importance for small object detection.

\textbf{Q2:} Provide FPS/latency and ONNX/TensorRT deployment results.\\
A: As shown in \cref{tab:across_arch}, we have reported FPS at 640×640, batch-size 1 on an A100 GPU. We have not performed official ONNX/TensorRT deployment yet, but will add standard deployment evaluation in the revised version.

\textbf{Q3:} Lack AP\_small metrics for small object detection.\\
A: As presented in \cref{tab:tide_nano}, we have provided APs (small-object AP) to evaluate small object detection performance.

\textbf{Q4:} Are YOLO variants trained with the same settings?\\
A: Thank you for the careful comment. All compared YOLO variants are trained with the same training strategy, input size, epochs, and augmentations. We will add a clear clarification in the revised manuscript.

\textbf{Q5:} Need FPS/latency to justify accuracy-efficiency trade-off.\\
A: As shown in \cref{tab:across_arch}, we have provided FPS measurements on an A100 GPU, which together with params and GFLOPs fully demonstrate the accuracy-efficiency trade-off.
